# v2.9.4 全局设置面板 + 未训练自动休息 设计说明

日期：2026-11-14
状态：已实现

## 1. 目标

1. 没训练的日子默认就是休息，不再需要每天手动打卡「今日休息」。
2. 今日训练页右上角新增设置入口，用一个面板统一管理可自定义按钮的显示/隐藏。

## 2. 开关清单与默认值

默认全部开启，即与旧版本界面完全一致。

| 开关 | 作用 | 关闭后隐藏的入口 |
| --- | --- | --- |
| 超级组 | 控制递减超级组 | 动作库训练方式卡、计划「设为超级组」、训练与历史里的超级组切换、阶梯编辑 |
| 左右组 | 控制左右分开记录 | 动作库与计划里的左右独立开关、训练与历史里的单侧切换 |
| 有氧记录 | 控制有氧模块 | 计划有氧设置、训练中有氧折叠区、完成页有氧确认、历史有氧编辑 |
| 备注入口 | 控制备注录入 | 训练、动作、计划、历史的备注输入；已有备注改为只读展示 |
| 补签休息 | 控制今日状态卡第三段 | 「补签」段；自动休息开启时该开关置灰且入口本来就不显示 |
| 自由训练 | 控制自由训练入口 | 今日页「自由训练（不选预设计划）」按钮 |
| 未练自动休息 | 未训练日自动记为休息 | 关闭后恢复手动「今日完全休息」按钮与旧统计口径 |

### 开关语义

开关只隐藏「新建 / 切换」入口，不销毁、不改写已有数据：

- 历史里已有的超级组、左右组、有氧、备注照常显示和统计。
- 当前动作已经处于超级组或单侧状态时，对应的取消入口仍然可见，避免无法回退。

## 3. 自动休息规则

- 读取时派生，不写入 localStorage。
- 起点：第一条真实记录（训练或手动休息）当天；最多回溯 400 天。
- 终点：昨天。今天仍可能开练，不提前记为休息。
- 已有任何记录的日期不覆盖。
- 自动休息记录带 `isAutoRest: true`，历史列表只读（无编辑/删除按钮），显示「自动」标记。
- 连续打卡、近 8 周日历、分化罗盘使用「真实记录 + 自动休息」的有效记录列表。
- 累计训练、本周训练、总完成组仍只统计训练，不受自动休息影响。

## 4. 设置面板

- 入口：今日训练页右上角齿轮。
- 形式：底部 Sheet，内容可滚动，背景点击 / Esc / 关闭按钮退出。
- 分组：「记录方式」四项 + 「今日页」三项。
- 每行展示名称、作用说明、右侧开关，整行可点击。
- 拨动即时保存并全局生效，不需要「保存」按钮。
- 底部「恢复默认设置」需二次确认。
- 设置存于 `localStorage` 的 `fitcustom_app_settings_v1`，未写入时使用默认值。
- 设置暂不写入备份 JSON，避免改变现有备份格式。

## 5. 技术落点

- `src/settings/appSettings.ts`：设置类型、默认值、读写与归一化。
- `src/settings/AppSettingsContext.tsx`：Provider 与 `useAppSettings()`。
- `src/settings/SettingsSheet.tsx`：设置面板。
- `src/ui/Toggle.tsx`：公共开关（用药页复用）。
- `src/utils/autoRest.ts`：自动休息派生。
- `src/App.tsx`：挂 Provider、管理面板开合。
- 四个页面按开关做入口显隐，日志页接入自动休息。

## 6. 验证

- `npm run build` 通过 TypeScript 与生产构建。
- 浏览器手机尺寸验证：
  - 7 个开关逐一开关，四个页面入口按预期变化；
  - 关闭后已有超级组、单侧、有氧、备注记录仍正常显示；
  - 自动休息开启：历史补出休息卡片、连续打卡连续、日历显示休息、今日无需打卡；
  - 自动休息关闭：恢复手动休息入口与补签段；
  - 刷新后设置保持；恢复默认可用。
